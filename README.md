# Nopeflix

A deliberately absurd fictional streaming-service front end with an original electric-blue brand identity.

## Brand

- Mirrored capital **N** + small **o** in electric blue.
- Remaining **peflix** wordmark in white.
- Matching SVG favicon.
- No Netflix red, logo treatment, catalogue, or proprietary assets.

## Experience

- Responsive React + Vite front end.
- GSAP scroll pinning and scrubbed text reveal.
- Animated title marquee.
- Hover-reactive movie cards.
- Search.
- "My Nope" watchlist state.
- Detail modal.
- Responsive horizontal genre accordion.
- Fictional comedy titles and seeded placeholder imagery.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

This is a front-end concept. Real authentication, catalogue licensing, playback, billing, recommendation infrastructure, and content delivery would need dedicated backend services before production use.
